### Problem:

The operator needs to soil temperature and soil moisture of earth to determine whether conditions are suitable for growing plants. If the temperature are too high or the moisture are too wet, conditions maybe unsuitable for some plants. Therefore, the system should alert the farmer so they can appropriate action.

### GOAL:

System will monitor and display the soil temperature and soil moisture. It will alert the farmer using LEDs when either reading falls outside its configured acceptable range.

### Components:

STM32: Receive and validate simulated readings from Arduino, compare them with configured thresholds, update the LCD, control the LEDs, and exchange commands and logs with the PC

Arduino: Generate simulated soil temperature and soil moisture readings, including normal and abnormal conditions for testing

LCD: Display soil temperature, soil moisture, and system status

LEDs: Indicate normal conditions, warnings, alarms, and communication faults

PC: Display and save received data for analysis, send start/stop commands and configure alert threshold

### Communication:

* SPI: STM32 acts as master and requests simulated soil temperature and soil moisture readings from Arduino, which acts as slave
* I2C: STM32 sends display updates to the LCD through its I2C backpack, showing readings and system status
* UART: STM32 sends readings, alerts and diagnostic messages to the PC. The PC sends start/stop commands and threshold settings to STM32



### User interaction:



User can monitor by PC, LCD and LEDs, they can change the thresholds and inspect faults on the PC.

### Scope:

* Version 1:The system will monitor simulated soil temperature and soil moisture generated by Arduino. It will display readings, provide LED alerts, and allow users to change thresholds and inspect faults through the PC
* Future versions: The system will use real soil sensors and add water monitoring

###### \### Required for version 1:

Arduino generates repeatable simulated readings.

STM32 requests and receives readings over SPI.

STM32 validates packets and detects stale data.

LCD displays values and operating status over I2C.

PC receives telemetry and sends commands over UART.

LEDs indicate normal, warning, alarm and communication failure.

Communication errors do not freeze the application.

PC saves logs for later inspection.



###### \### Extensions after version 1:

Real sensors.

FreeRTOS.

DMA.

A graphical PC dashboard.

Onboard persistent storage.

Calendar timestamps using an RTC.

### Completion:

The project will be considered complete when the system correctly receives, validates, and displays simulated soil temperature and soil moisture. A demonstration will show LED alerts, threshold changes, start/stop commands, and recovery from communication faults. Test logs will confirm that these features work and that the system runs continuously for two hours without freezing or unexpectedly resetting
